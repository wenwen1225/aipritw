掉卡順序紀錄器

手機網頁版，用來記錄機台左右道的掉卡順序。

目前規則：
- 001–019：四星卡
- 020–040：三星卡
- 041–056：二星卡
- 無 057–060
- 簽卡不固定綁定卡號，記錄前可另外點選「✍️ 簽卡」
- 簽卡記錄完成後會自動切回「一般版本」，避免下一張誤標

功能：
- 左／右道切換
- 001–056 快速點卡
- 星等依卡號自動判定
- 簽卡額外標記
- 四星掉卡以金色／✨ 特別標記
- 左右道分開計算「掉幾張普卡後出四星」
- 四星出現後，該道普卡累積自動歸零重新計算
- 完成本局與歷史紀錄都會保留每次四星前的普卡數
- 撤銷上一張後會自動重新計算四星間隔
- 完整掉卡順序與左右道各自順序
- 歷史紀錄保存在瀏覽器
- 複製文字、匯出 CSV（含四星前普卡數）

普卡計算規則：
- 2★、3★ 的一般版本算普卡
- 簽卡不算普卡
- 4★ 為四星事件，不算普卡
