# 抽卡紀錄：Google Sheets 雲端同步設定

目前變更僅位於 GitHub 分支 `feature/google-sheets-sync`，不影響正式版 main。

## 建立雲端表格

1. 前往 https://sheets.new 建立空白 Google 試算表，建議命名「抽卡遊玩紀錄」。
2. 在該試算表中開啟「擴充功能 → Apps Script」，將 `gas/Code.gs` 的**完整內容**貼入 Code.gs 並儲存。
3. 於 Apps Script 選擇 `setupCloud`，按「執行」，依畫面授權。
4. 在「執行記錄」找到 `同步金鑰` 並安全保存，**絕不可提交到 GitHub**。
5. 點「部署 → 新增部署 → 網頁應用程式」，設定「執行身分：我」、「誰可以存取：任何人」，按部署，複製以 `/exec` 結尾的網址。
6. 開啟測試版網站（Vercel Preview 或本機預覽），點「☁ 雲端設定」，貼上 `/exec` 網址和同步金鑰。
7. 按「↻ 同步雲端」，確認網站顯示同步完成，並在 Google Sheets 查看兩張表：`遊玩局數總覽` 與 `完整掉卡紀錄`。

## 功能與安全

- 既有歷史紀錄會在首次同步時上傳；新局完成後自動嘗試同步，失敗時保留本機資料供重試。
- 本局進行中的掉卡紀錄另存於瀏覽器，重新整理仍可接續；**尚未完成的局不會上傳雲端**。
- 刪除歷史紀錄時會加入待同步刪除清單；雲端標記 deleted 以免其他裝置重新上傳。
- 手機與電腦各自填入相同網址及金鑰後可同步完成的局。
- GAS 以「任何人」部署，知道 /exec URL 和同步金鑰的人可以存取資料；金鑰留在瀏覽器本機，請不要分享、截圖或提交至公開倉庫。
- 不建議在多人共用或公共裝置保存金鑰。
- GAS 服務部署與實際表格寫入尚需手動授權和端對端測試；此分支尚未接正式版。

## 測試流程

1. 先備份原本瀏覽器的歷史資料（勿清除網站資料），在測試版設定雲端後檢查舊局是否上傳。
2. 連續記錄 3 張，重新整理確認本局仍在；儲存並開新局，確認 Google Sheets 新增 1 局與 3 筆掉卡。
3. 再按一次同步，確認沒有重複新增。
4. 第二台裝置輸入相同的同步資料，確認可以讀取第一台的完整紀錄。
5. 測試離線儲存與恢復同步，以及刪除後另一裝置不會復活被刪的紀錄。

**注意：** 目前沒有 Google 帳號登入或細緻的存取控管；金鑰是個人使用的簡易保護，不等同於完整的使用者認證。
